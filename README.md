# Sonematic

A binaural-beat engine for rest, meditation, focus and flow: a carrier tone with a beat offset between the
ears, a harmonic stack, a sub-octave and a white, pink or brown noise bed.

**Open it:** <https://rick-masterson.github.io/sonematic/>. Headphones are needed for the binaural effect.

## Install as an app

It runs as a standalone app and works offline once installed:

- **Android (Chrome):** menu → *Install app* / *Add to Home screen*.
- **iPhone/iPad (Safari):** Share → *Add to Home Screen*.
- **Desktop (Chrome/Edge):** the install icon in the address bar.

You can also download `index.html` and open it directly; it works as a single file (without offline caching).

## Development

No build step: edit `index.html` and open it. Tests run in headless Firefox:

```sh
tests/run.sh
```
